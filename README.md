# My Cycle v2

Minimal-maximalist regl takip uygulaması.

## Çalıştırma
`index.html` dosyasını tarayıcıda açın.

## Netlify
GitHub reposuna `index.html` kök dizinde olacak şekilde ekleyin. Build command boş, publish directory `.`.

## Gizlilik
Veriler bu sürümde yalnızca tarayıcının localStorage alanında tutulur. Çok kullanıcılı bulut veritabanı henüz eklenmedi. Tahmini ovülasyon ve doğurganlık tarihleri gebelikten korunma amacıyla kullanılmamalıdır.
